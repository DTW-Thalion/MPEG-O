.. py:class:: Subject

   A study Subject: the donor / patient / animal / object the
   sample was drawn from.

   :param external_id: Stable, depositor-controlled identifier; primary key within the
                       dataset. Required, non-empty, must not contain ``'/'`` (HDF5
                       group-name restriction, see format-spec §11).
   :type external_id: str
   :param project: Study acronym / cohort identifier. Free string. ``""`` = unset.
   :type project: str, default ""
   :param sex: Free string (e.g. ``"M"``, ``"F"``, ``"NA"``). No enumeration
               enforced. ``""`` = unset.
   :type sex: str, default ""
   :param birth_year: Four-digit year of birth, or ``0`` sentinel for unknown. Stored
                      as int64 on disk; widened to int32 in the
                      ``SUBJECT_METADATA`` Arrow transport payload (column-width
                      consistency with the identification table).
   :type birth_year: int, default 0
   :param attributes: Open extension slot. Keys are free strings; values are
                      stringified. Serialised on disk as a sort-keys JSON object so
                      the bytes are deterministic across Python / ObjC / Java.
   :type attributes: dict[str, str], default {}

   .. rubric:: Notes

   API status: Stable.

   Cross-language equivalents
   --------------------------
   Objective-C: ``TTIOSubject`` · Java:
   ``global.thalion.ttio.Subject``.
