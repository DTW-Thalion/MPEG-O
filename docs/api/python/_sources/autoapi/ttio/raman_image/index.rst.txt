.. py:class:: RamanImage

   Bases: :py:obj:`ttio.image.Image`


   Raman hyperspectral imaging dataset: a ``width × height`` grid of
   pixels, each pixel a spectrum of ``spectral_points`` intensity values
   sampled at a shared rank-1 ``wavenumbers`` axis.

   :param width: Image grid dimensions in pixels.
   :type width: int, default 0
   :param height: Image grid dimensions in pixels.
   :type height: int, default 0
   :param spectral_points: Number of float64 intensity values per pixel.
   :type spectral_points: int, default 0
   :param intensity: Rank-3 intensity cube of shape ``(height, width, spectral_points)``.
   :type intensity: numpy.ndarray, default empty rank-3 array
   :param wavenumbers: Rank-1 wavenumber axis of length ``spectral_points`` (1/cm).
   :type wavenumbers: numpy.ndarray, default empty rank-1 array
   :param pixel_size_x: Spatial pixel size (implementation-defined units).
   :type pixel_size_x: float, default 0.0
   :param pixel_size_y: Spatial pixel size (implementation-defined units).
   :type pixel_size_y: float, default 0.0
   :param scan_pattern: Scan pattern label (``"raster"``, ``"random_access"``, ...).
   :type scan_pattern: str, default ""
   :param tile_size: HDF5 chunk tile size for reads; 0 means native cube chunks.
   :type tile_size: int, default 0
   :param excitation_wavelength_nm: Laser excitation wavelength in nanometres.
   :type excitation_wavelength_nm: float, default 0.0
   :param laser_power_mw: Incident laser power in milliwatts.
   :type laser_power_mw: float, default 0.0
   :param title: Dataset-level metadata.
   :type title: str, default ""
   :param isa_investigation_id: Dataset-level metadata.
   :type isa_investigation_id: str, default ""
   :param identifications: Dataset-level composition fields (ObjC inherits these from
                           ``TTIOSpectralDataset``).
   :type identifications: list, default []
   :param quantifications: Dataset-level composition fields (ObjC inherits these from
                           ``TTIOSpectralDataset``).
   :type quantifications: list, default []
   :param provenance_records: Dataset-level composition fields (ObjC inherits these from
                              ``TTIOSpectralDataset``).
   :type provenance_records: list, default []

   .. py:method:: write_to(study_group) -> None

      Write this Raman image cube under ``<study_group>/raman_image_cube/``.

      Mirrors :meth:`global.thalion.ttio.RamanImage.writeTo` — intensity
      as a 3-D ``[h, w, sp]`` dataset, ``wavenumbers`` 1-D dataset,
      and Raman-specific scalar attributes.

      Pixel size attributes are written as **native double** (not strings),
      applying the PR #31 lesson immediately so legacy-string reads remain
      backwards-compatible via :meth:`read_from`.



   .. py:method:: read_from(study_group) -> RamanImage | None
      :classmethod:


      Read a Raman image cube from a study group; return None if absent.

      Accepts both the native-double form (written by this class) and
      the legacy string form for pixel_size_x/y,
      excitation_wavelength_nm, and laser_power_mw.
