ttio.tools.fastq_export_cli
===========================

.. py:module:: ttio.tools.fastq_export_cli

.. autoapi-nested-parse::

   FASTQ export CLI — emits a genomic run as a FASTQ file.

   Usage
   -----
   ::

       python -m ttio.tools.fastq_export_cli \
           --in study.tio --name genomic_0001 --out reads.fq.gz

   Exit codes
   ----------
   - ``0`` — wrote output successfully.
   - ``1`` — argument error.
   - ``2`` — read / write failure.

Module Contents
---------------

.. py:function:: main(argv: list[str] | None = None) -> int

   Emit a genomic run from a ``.tio`` container as a FASTQ file.

   The output Phred offset defaults to ``33`` and may be overridden
   with ``--phred``.

   :param argv: Argument vector. Defaults to ``sys.argv[1:]`` when ``None``.
   :type argv: list[str], optional

   :returns: *int* -- ``0`` on success, ``2`` on I/O / lookup failure. Argparse
             exits with ``2`` on usage errors.
