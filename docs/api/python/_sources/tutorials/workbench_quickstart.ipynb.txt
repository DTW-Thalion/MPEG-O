    "# Workbench client quickstart\n",
    "\n",
    "This tutorial walks the spec §8.3 end-to-end flow with the TTI-O\n",

    "The Java SDK (`global.thalion.ttio.workbench.WorkbenchClient`) mirrors\n",
    "this surface method-for-method (workplan Decision 2: Python + Java\n",
    "lockstep)."

    "## 1. Connect\n",
    "\n",
    "`ttio.connect(url, auth=...)` authenticates and returns a\n",
    "`WorkbenchClient`. Pick an auth provider for your deployment —\n",
    "`PasswordTotpAuth` (interactive), `BearerAuth` (a pre-issued token),\n",
    "or `BootstrapAdminAuth` (a daemon staging-root, smoke/dev only)."
   ]
  },

   "execution_count": null,

   "source": [
    "import ttio\n",
    "from ttio.workbench import PasswordTotpAuth\n",
    "\n",
    "client = ttio.connect(\n",
    "    \"wss://biobank.example.org:8443/transport\",\n",
    "    auth=PasswordTotpAuth(username_=\"alice\", password=\"…\", totp=\"012345\"),\n",
    ")\n",
    "print(client.session.username, sorted(client.session.capabilities))"
   ]

    "## 2. Encode a source file to `.tio`\n",
    "\n",

    "bruker-timstof`."
   ]
  },
  {

   "outputs": [],
   "source": [
    "from ttio.importers import registry as import_registry\n",
    "\n",
    "import_registry.encode(\"mzml\", [\"sample.mzML\"], \"sample.tio\")"
   ]
  },

   "cell_type": "markdown",

   "source": [
    "## 3. Upload\n",
    "\n",
    "`upload_bytes` streams a buffered `.tio`/`.tis` to a container URI under\n",
    "a project. For an encrypted upload, encrypt the channel payloads\n",
    "per-AU inside a valid `.tis` (the daemon never holds a key): use\n",
    "`upload_encrypted` (BYOK, caller-held key), `upload_encrypted_envelope`\n",
    "(per-run DEK wrapped under a symmetric KEK), or `upload_encrypted_pqc`\n",
    "(ML-KEM-1024-wrapped DEK, preview-gated). See\n",
    "`docs/workbench-client/per-au-encrypted-upload-plan.md`."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "import asyncio\n",
    "\n",
    "with open(\"sample.tio\", \"rb\") as f:\n",
    "    payload = f.read()\n",
    "\n",
    "result = asyncio.run(client.upload_bytes(\n",
    "    project=\"alpha\",\n",
    "    container_uri=\"uri:tio:alpha-sample\",\n",
    "    data=payload,\n",
    "))\n",
    "print(result.container_uri, result.last_acked_au_sequence)"
   ]

    "\n",
    "List containers in a project, or run a cohort predicate. `preview_count`\n",

  },

   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "## 5. Submit a pipeline\n",
    "\n",
    "Register (or look up) a pipeline, submit a job, and poll to a terminal\n",
    "state. `jobs().events()` is an SSE long-poll alternative to polling\n",
    "`jobs().get()`."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "import time\n",
    "\n",
    "jobs = client.jobs()\n",
    "job = jobs.submit(\n",
    "    pipeline_id=\"eqtl-analysis\",\n",
    "    inputs={\"container\": \"uri:tio:alpha-sample\"},\n",
    "    params={},\n",
    ")\n",
    "while True:\n",
    "    cur = jobs.get(job.job_id)\n",
    "    if cur.state in (\"succeeded\", \"failed\", \"cancelled\"):\n",
    "        break\n",
    "    time.sleep(1.0)\n",
    "print(\"final state:\", cur.state)"
   ]
  },

    "## 6. Download the result\n",
    "\n",
    "`download_bytes` materialises a container (optionally with a\n",
    "selective-access filter) to a buffered byte string. For an encrypted\n",
    "container, the matching `download_decrypted` (BYOK),\n",
    "`download_decrypted_envelope` (symmetric KEK), or\n",
    "`download_decrypted_pqc` (ML-KEM) materialises the still-encrypted\n",
    "`.tio` and decrypts it client-side."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "dl = asyncio.run(client.download_bytes(\n",
    "    container_uri=\"uri:tio:alpha-sample-eqtl\",\n",
    "    filters={\"chromosome\": \"chr6\"},\n",
    "))\n",
    "with open(\"result.tio\", \"wb\") as f:\n",
    "    f.write(dl.payload)\n",
    "print(\"wrote\", len(dl.payload), \"bytes\")"
   ]
