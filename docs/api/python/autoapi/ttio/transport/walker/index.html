ttio.transport.walker¶

Dataset walker — produces transport-stream events from a SpectralDataset filtered through an AUFilter.

This is the Python equivalent of the ObjC TTIODatasetWalker and Java DatasetWalker. Where ObjC/Java use a visitor protocol, the Python form is a generator that yields WalkerEvent instances — more idiomatic and trivially composable with async producers via async for adapters.

Used by:

  • ttio.transport.server._emit_stream() — encodes each event as a transport packet.

  • Workbench Server S3 (out-of-tree) — drives binary, stats-only, and stats-with-payload download modes from the same iteration.

ttio.transport.walker.walk_dataset(dataset: ttio.spectral_dataset.SpectralDataset, filter: ttio.transport.filters.AUFilter | None = None) → Iterator[WalkerEvent][source]¶

Generator that yields the canonical transport-stream event sequence for the given dataset:

1. StreamHeaderEvent once. 1a. v0.11 §5.4 prelude events (when populated):

EncryptionAlgorithmEvent, DatasetProvenanceEvent, SubjectMetadataEvent, SampleMetadataEvent, ReferenceGroupEvent (one per reference, sorted by URI key), ImageEvent, RamanImageEvent, IRImageEvent, IdentificationsTableEvent, QuantificationsTableEvent.

  1. DatasetHeaderEvent per matched dataset.

  2. AccessUnitEvent per matched AU (spectral + genomic).

  3. EndOfDatasetEvent per matched dataset.

  4. EndOfStreamEvent once.

Iteration order matches TransportWriter.write_dataset() — the byte form emitted by encoding the events one-by-one is identical to the unfiltered writer output (mod filter cuts).

Parameters:

  • dataset – A SpectralDataset to walk.

  • filter – Optional AUFilter. None emits every AU in dataset iteration order.
