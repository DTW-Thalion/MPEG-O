Conforms To: TTIOEncryptable

Declared In: Dataset/TTIOSpectralDataset.h

Root container for a TTI-O .tio file. Owns a top-level study/ group plus zero or more named MS acquisition runs, NMR spectrum collections, genomic runs, and the dataset-wide identifications, quantifications, provenance records, and an optional transition list.

Persistence is via -writeToFilePath:error: / +readFromFilePath:error: which open or create the underlying HDF5 file directly. The class also provides several +writeMinimalToPath: overloads — flat-buffer fast paths that bypass per-spectrum object construction for callers with already-flattened channel data (importers, numerical producers).

API status: Stable.

Cross-language equivalents:
Python: ttio.spectral_dataset.SpectralDataset
Java: global.thalion.ttio.SpectralDataset

decryptInPlaceAtPath: withKey: error: 

+ (BOOL) decryptInPlaceAtPath: (NSString*)path withKey: (NSData*)key error: (NSError**)error;
Persist-to-disk decrypt. Strips AES-256-GCM encryption from the .tio file at path : for every MS run with an encrypted intensity channel, writes the plaintext back as intensity_values and removes the encrypted siblings. Finally clears the root @encrypted attribute so -isEncrypted returns NO when the file is reopened.

Symmetric with -encryptWithKey:level:error: (which leaves the root attribute set). After this call the file is byte-compatible with the pre-encryption layout. The file must not be held open by another writer.

writeMinimalToPath: title: isaInvestigationId: mixedRuns: genomicRuns: identifications: quantifications: provenanceRecords: error: 

+ (BOOL) writeMinimalToPath: (NSString*)path title: (NSString*)title isaInvestigationId: (NSString*)isaId mixedRuns: (NSDictionary*)mixedRuns genomicRuns: (NSDictionary*)genomicRuns identifications: (NSArray*)identifications quantifications: (NSArray*)quantifications provenanceRecords: (NSArray*)provenance error: (NSError*_Nullable*_Nullable)error;
Canonical mixed-dictionary write API. Accepts a single mixedRuns dict whose values may be either TTIOWrittenRun (MS) or TTIOWrittenGenomicRun (genomic); dispatches per-value via -isKindOfClass: to the right write path.

genomicRuns may also be supplied; a name appearing in BOTH dicts populates error rather than silently picking one. Unsupported value classes in mixedRuns also produce an error.

writeMinimalToPath: title: isaInvestigationId: mixedRuns: genomicRuns: identifications: quantifications: provenanceRecords: progress: error: 

+ (BOOL) writeMinimalToPath: (NSString*)path title: (NSString*)title isaInvestigationId: (NSString*)isaId mixedRuns: (NSDictionary*)mixedRuns genomicRuns: (NSDictionary*)genomicRuns identifications: (NSArray*)identifications quantifications: (NSArray*)quantifications provenanceRecords: (NSArray*)provenance progress: (TTIOProgressBlock)progress error: (NSError*_Nullable*_Nullable)error;
Progress-aware overload of the canonical +writeMinimalToPath: ...mixedRuns: write API.

Emits a baseline {@code (0, total)} fire + one {@code (idx, total)} fire per non-empty section in §5.4 order (encryption / provenance / subjects / samples / references / image / identifications / quantifications / runs). Empty sections are skipped. Pass {@code nil} for {@code progress} to skip callbacks. Mirrors Java + Python.

+ (BOOL) writeMinimalToPath: (NSString*)path title: (NSString*)title isaInvestigationId: (NSString*)isaId msRuns: (NSDictionary*)runs genomicRuns: (NSDictionary*)genomicRuns identifications: (NSArray*)identifications quantifications: (NSArray*)quantifications provenanceRecords: (NSArray*)provenance error: (NSError*_Nullable*_Nullable)error;

writeMinimalToPath: title: isaInvestigationId: msRuns: identifications: quantifications: provenanceRecords: error: 

+ (BOOL) writeMinimalToPath: (NSString*)path title: (NSString*)title isaInvestigationId: (NSString*)isaId msRuns: (NSDictionary*)runs identifications: (NSArray*)identifications quantifications: (NSArray*)quantifications provenanceRecords: (NSArray*)provenance error: (NSError*_Nullable*_Nullable)error;
Flat-buffer fast write path. Bypasses per-spectrum object construction and the channel-concat that -writeToFilePath:error: performs when given a TTIOAcquisitionRun of TTIOMassSpectrum objects. Callers that already have flat buffers (e.g. importers reading mzML in bulk, numerical producers) pass TTIOWrittenRun instances and skip both costs.

Writes the same on-disk layout as -writeToFilePath: , so readers do not distinguish files produced by the two paths.

Releases the underlying HDF5 file handle. After this call any further lazy hyperslab reads on contained runs will fail. Required before calling -encryptWithKey:level:error: so the encryption manager can reopen the file read-write. Idempotent.

decryptWithKey: error: 

- (BOOL) decryptWithKey: (NSData*)key error: (NSError**)error;
In-process decrypt overlay for an encrypted dataset. The plaintext intensity channels become visible to subsequent reads on this instance; the on-disk file is not modified (call +decryptInPlaceAtPath:withKey:error: for persistent decrypt). @param key 32-byte AES-256 key matching the one used at encrypt time. @param error On failure (e.g. wrong key, tag mismatch), populated with an NSError describing the cause. May be NULL. @return YES on success, NO on failure.

encryptWithKey: level: error: 

- (BOOL) encryptWithKey: (NSData*)key level: (TTIOEncryptionLevel)level error: (NSError**)error;
Encrypt the dataset's intensity payload in place under AES-256-GCM. After this call the dataset's HDF5 file holds ciphertext instead of plaintext intensity channels and -isEncrypted returns YES. @param key 32-byte AES-256 key material. @param level Granularity: per-dataset, per-run, or per-AU. @param error On failure, populated with an NSError describing the cause. May be NULL. @return YES on success, NO on failure.

imageForKind: 

- (TTIOImage*) imageForKind: (TTIOImageKind)kind;
The embedded image for the requested modality, or nil when the corresponding cube group is absent. The image is read and materialised lazily from the dataset file on first access and cached per kind. Returns the polymorphic TTIOImage base; callers needing a concrete subclass cast the result (e.g. (TTIOMSImage *)[ds imageForKind:TTIOImageKindMS] ).

Java parity: SpectralDataset.imageForKind(...). Python parity: SpectralDataset.image_for_kind(...).

@since 1.2.0

images 

- (nonnull NSArray*) images;
All embedded images present on this dataset, in modality order (MS, Raman, IR), skipping any kind whose cube group is absent. @since 1.2.0
