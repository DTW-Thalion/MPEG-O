## Server-side survey (kickoff input)

Surveyed `~/tti-workbench-server/Source/HTTP/handlers/TTIOWBContainersHandler.{h,m}`
for the wire contract. Endpoints + response shapes:

```
GET    /v1/containers              -- paginated list
GET    /v1/containers/{uri}        -- detail (adds size_bytes + modified_at)
GET    /v1/containers/{uri}/layers -- per-layer breakdown
GET    /v1/containers/{uri}/manifest -- run/spectrum summary
DELETE /v1/containers/{uri}        -- gated server-side delete
```

List rows: `{uri, project, owner, encrypted, storage_path,
created_at, updated_at}` -- all timestamps Unix epoch seconds.
Query params: `project`, `owner`, `limit` (default 50, max 500),
`cursor` (opaque base64url). Pagination cursor encodes
`{last_uri, query_hash}` server-side; the client treats it as
opaque.

Capability gates (server-side, not enforced client-side):
`containers.read.any_project` for cross-project reads;
`containers.delete.any` / `containers.delete.own_uploads` for
delete. Anonymous users see nothing; existence is never leaked
(404 vs 403).

## Cross-language byte-equivalence

The `GET /v1/containers` list-page parser is the W5.2
cross-language anchor. The literal JSON pinned in
`test_containers.test_list_page_parses_canonical_anchor`
(Python) and `ContainersTest.listPageParsesCanonicalAnchor`
(Java) must produce identical record fields:

```json
{
  "containers": [
    {"uri": "uri:tio:alpha-001", "project": "alpha", "owner": "alice",
     "encrypted": false, "storage_path": "/srv/alpha/001.tio",
     "created_at": 1700000000, "updated_at": 1700000600},
    {"uri": "uri:tio:alpha-002", "project": "alpha", "owner": "bob",
     "encrypted": true,  "storage_path": "/srv/alpha/002.tio",
     "created_at": 1700001000, "updated_at": 1700001600}
  ],
  "next_cursor": "eyJsYXN0X3VyaSI6ICJ1cmk6dGlvOmFscGhhLTAwMiJ9"
}
```

Fourth independent cross-language anchor in the workbench client
(W1 handshake, W3 cohort predicate, W4 attach handshake, W5.2
container list-page).
