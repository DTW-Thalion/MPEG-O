# W5.3 progress

Status snapshot for the **Upload/Download Manager + Selective
Access Panel** sub-phase per
[`docs/workbench-client/W5-plan.md`](W5-plan.md).

## Status (2026-05-19): COMPLETE -- in review

Third W5 sub-phase. Wires the W1 `WorkbenchTransportClient` into
a JavaFX queue UI, adds a visual filter builder for selective
downloads, and pins a typed-builder filter API on both SDKs.

## Server-side reuse (no new wire surface)

W5.3 introduces **no new server endpoints**. It builds on top
of the existing W1 `/transport` WS handshake. The
download-filter allowlist (validated server-side, mirrored by
the W1 handshake builder) is unchanged:

```
ms_level, polarity, retention_time_min, retention_time_max,
precursor_mz_min, precursor_mz_max, precursor_charge, max_au
```

What W5.3 adds is a **typed builder** on both SDKs so a GUI
consumer (or other SDK caller) can construct a server-ready
filter map with per-key + cross-key validation, instead of
passing a raw `Map<String, Object>` and discovering bad keys at
WS handshake time.

## Deliverables

### Java SDK (`java/src/main/java/global/thalion/ttio/workbench/transport/`)

| File | Purpose |
|---|---|
| `SelectiveAccessFilter.java` | Fluent builder with typed setters (`msLevel(int)`, `polarity(String)`, `retentionTimeMin/Max(double)`, `precursorMzMin/Max(double)`, `precursorCharge(int)`, `maxAu(int)`). Per-key range checks throw `IllegalArgumentException`; cross-key `validate()` checks `rt_max >= rt_min` and `mz_max >= mz_min` and throws `IllegalStateException`. `build()` returns a `LinkedHashMap<String, Object>` ready for `WorkbenchTransportClient.download`. |

### Python SDK (`python/src/ttio/workbench/transport/`)

| File | Purpose |
|---|---|
| `selective_access.py` | Single-class mirror of the Java builder. Same method names (snake_case), same exception semantics (`ValueError` per-key, `RuntimeError` cross-key). |

### tio-browser GUI (`tio-browser/.../workbench/`)

| File | Purpose |
|---|---|
| `TransferKind.java` | Enum: `UPLOAD` / `DOWNLOAD`. |
| `TransferState.java` | Enum: `PENDING` / `RUNNING` / `COMPLETED` / `FAILED`. `isTerminal()` helper. |
| `Transfer.java` | Mutable queue entry with JavaFX properties (`stateProperty`, `bytesTransferredProperty`, `messageProperty`). |
| `TransferManager.java` | Process-wide singleton. `enqueueUpload(...)` / `enqueueDownload(...)` push tasks onto a daemon-thread executor and return the queued `Transfer`. Worker threads marshal state mutations to the FX thread via `Platform.runLater`. |
| `SelectiveAccessPanel.java` | GridPane filter form with one input per allowed filter key. `buildFilter()` delegates to the SDK `SelectiveAccessFilter` builder and runs the cross-key `validate()`. Static `parseInt` / `parseDouble` helpers normalise empty / non-numeric / out-of-range input to "skip this key." |
| `UploadStartDialog.java` | Modal Stage with source file picker + project + container URI; static validators for project (non-blank) and URI (starts with `uri:tio:`). |
| `DownloadStartDialog.java` | Modal Stage with URI + destination + embedded `SelectiveAccessPanel`. On submit, calls `panel.buildFilter()` and enqueues via `TransferManager`. |
| `TransferQueueView.java` | Non-modal Stage with a TableView<Transfer> bound to the manager's observable list. Indeterminate ProgressBar while RUNNING; full bar on COMPLETED. |

`MainWindow.java` integration: three new menu items under
`Workbench` -- `Upload to workbench...`,
`Download from workbench...`, `Transfers...`.

## Cross-language byte-equivalence

The canonical filter dict produced by the builder is the W5.3
cross-language anchor. The literal builder input pinned in
`test_selective_access.test_canonical_filter_anchor` (Python)
and `SelectiveAccessFilterTest.canonicalFilterAnchor` (Java)
must produce the same map:

```json
{
  "ms_level":           2,
  "polarity":           "positive",
  "retention_time_min": 12.5,
  "retention_time_max": 25.0,
  "precursor_mz_min":   100.0,
  "precursor_mz_max":   2000.0,
  "precursor_charge":   2,
  "max_au":             50
}
```

Fifth independent cross-language anchor in the workbench client
(W1 handshake, W3 cohort predicate, W4 attach handshake,
W5.2 container list-page, W5.3 selective-access filter).

## Deferred to W5.3 follow-up

- **Live daemon round-trip smoke** -- shared with W1/W3/W4/W5.1/W5.2.
- **True progress percentage** -- the W1 transport client does
  not expose per-AU progress callbacks; v1.0 of the queue view
  shows indeterminate progress while RUNNING and full bar on
  COMPLETED. A progress-callback API on `WorkbenchTransportClient`
  is needed first.
- **Pause / cancel** -- needs a cancellation primitive on the
  W1 client. Tracked here as a v1.1 enhancement.
- **Chromosome / position filters** -- not in the v1.0 server's
  download-filter allowlist. Genomic selective access can ship
  when the server adds the corresponding handler.
