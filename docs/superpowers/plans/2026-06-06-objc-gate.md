# ObjC Coverage Gate — Enforce + Scope (R2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make the ObjC coverage threshold a real CI gate: scope the lcov to `objc/Source` + `objc/Tools`, recalibrate the threshold to the scoped baseline, close the silent escape hatches (via a `TTIO_COV_STRICT` mode CI sets), and drop `continue-on-error`.

**Architecture:** `objc/build.sh --coverage` computes `cov_pct` by summing `LH:`/`LF:` from the same `coverage.lcov` it exports — so scoping the `llvm-cov export` auto-scopes the gate. Script + CI config only; no `.m`/`.h`/test change.

**Tech Stack:** bash, llvm-cov/llvm-profdata 18, GitHub Actions.

    # coverage must FAIL rather than silently pass — otherwise an

    # --coverage builds default to non-strict (graceful) behavior.
    cov_strict="${TTIO_COV_STRICT:-0}"

Then change the three `exit 0` escape hatches so they `exit 1` when strict, keeping `exit 0` otherwise:

(a) no-profraw hatch (~78-81): replace `exit 0` with:

(b) llvm-tools-missing hatch (~99-105): same — replace its `exit 0` with `[ "$cov_strict" = "1" ] && exit 1 || exit 0`.

(c) no-test-binary hatch (~136-139): same — replace its `exit 0` with `[ "$cov_strict" = "1" ] && exit 1 || exit 0`.

Add a short comment at each that strict mode fails here. (Leave all the diagnostic `echo`s intact.)
